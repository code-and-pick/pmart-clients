# 직원 웹 화면 점검(ui-check)

2026-11-20. 백오피스 AWS 개편 때 쓴 검사를 모았습니다. 인사·MFC·라이더 백오피스도 같은 기준으로 점검합니다(`docs/apps/backoffice-ui-guide.md`).

## 쓰는 법

1. 목 모드로 앱을 띄우고 로그인합니다. 개발 서버는 사용자가 띄웁니다.
2. 브라우저 개발자 도구 콘솔에 `ui-check.js` 내용을 붙여 넣습니다.
3. 아래처럼 부릅니다.

| 부르기 | 보는 것 |
|---|---|
| `await uiCheck.all()` | 지금 화면 — 글자 겹침, 이름표·칸 간격, 체크 옆 글자, 단추 붙음, 고르기 칸 가운데 맞춤, 화면 밖 넘침, 한 글자씩 세로로 쌓임. 어두운 화면이면 대비 2.6 미만도 |
| `await uiCheck.pages(['/a', '/b'])` | 여러 화면을 차례로 봅니다. 같은 탭에서 주소만 바꿔서 로그인이 유지됩니다 |
| `await uiCheck.narrow(1024, ['/a'])` | 같은 출처 iframe 을 1024px 로 띄워서 봅니다. 창 크기는 바꾸지 않습니다. iframe 안에서 다시 로그인해야 할 수 있습니다 |
| `uiCheck.csp()` | 이 탭에 실서버와 같은 CSP(`style-src 'self'`)를 겁니다. 화면을 써 본 뒤 `uiCheck.blocked` 에 막힌 것이 모입니다 |

## 주의

- **읽기만 합니다.** 누르거나 저장하지 않습니다.
- **0 건이어도 눈으로 한 번 더 봅니다.** 이 검사는 정해 둔 모양만 잡습니다. 고친 칸은 확대해서 직접 확인합니다(2026-11-20, 고친 것이 고르기 칸 가운데 맞춤을 깨뜨린 일이 있었습니다).
- **실서버 CSP 때문에 화면에 `<style>` 태그를 쓰지 않습니다.** 동적 스타일은 React `style={{}}` 나 `element.style` 로 넣습니다.
