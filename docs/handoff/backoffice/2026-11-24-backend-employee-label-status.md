# 직원 이름표에 재직 상태 요청 (사번으로 사람 고를 때 정지 직원 경고)

보낸 앱: backoffice (PC 2)
받는 백엔드 영역: platform (hr-service — employee-labels, HR-5 이어서)

- 근거: 사용자 2026-11-24 결정 — 교대 인계 후임·접수 건 배정에서 사번으로 사람을 고를 때 **정지(SUSPENDED) 직원은 "보이되 경고"**. (퇴사자는 hr 0.11.0 activeOnly=true 로 이미 빠진다.)
- 지금 받는 것: `GET /hr/employee-labels?employeeNos=…&activeOnly=true` → `{items:[{operatorId, name, employeeNo}]}` — **상태가 없어** 정지 직원을 화면이 알아볼 수 없다.
- 왜 필요한가: 정지 직원은 로그인할 수 없다. 인계를 받으면 수락 전(PENDING)에 멈추고, 접수 건을 맡기면 아무도 처리하지 않는다. case 는 맡기기·인계 작성 때 재직 여부를 보지 않는다(통합백오피스 백엔드 정정 2026-11-24).

## 요청
- `EmployeeLabel` 에 `status`(hr 직원 상태 그대로 — ACTIVE·SUSPENDED·LEFT 등)를 더해 주세요. 이름표만 쓰는 화면이 많아 선택 필드(없으면 화면은 지금처럼)로.
- 개인정보가 아닌 상태 값만이라 지금 권한(직원 토큰이면 누구나) 그대로면 좋겠다. 어렵다면 `employeeNos` 로 부를 때만 실어 줘도 된다.

## 받은 뒤 화면
- 확인 줄: 정지 직원이면 "[이름] · 사번 — 정지 중이라 로그인할 수 없어요(인계를 받지 못하고, 맡겨도 처리하지 못해요)" 경고를 띄우고, 그래도 고를 수는 있게(사용자 결정 "보이되 경고").
