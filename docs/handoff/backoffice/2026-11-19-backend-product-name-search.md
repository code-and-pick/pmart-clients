# 상품 목록 이름 검색 요청 (백오피스 상품 조회)

보낸 앱: backoffice (PC 2)
받는 백엔드 영역: platform (product-service) — 담당이 다르면 알려 달라

- 근거: 사용자 2026-11-19 "상품 찾을 때 상품 이름으로 검색이 안 되는지". 상품 조회 화면(`/products`)에서 이름으로 찾고 싶다.
- 지금 `GET /products`(listProducts)의 거르기는 `categoryId`·`saleState`·`cursor`·`size` 뿐이다.
- 그래서 화면은 **지금 불러온 쪽(50개) 안에서만** 관리용 명칭·고객용 상품명으로 거른다. 쪽이 더 있으면 "다음 쪽을 불러와 주세요"라고 안내한다. 상품이 늘면 원하는 상품을 찾기 어렵다.

## 요청

### PN-1 `GET /products` 에 이름 검색 `q`

- `q`(선택, 문자열 1~50자): **관리용 명칭(`internalName`)** 에 들어 있는 상품만(부분 일치, 대소문자·띄어쓰기 무시면 좋겠다).
- 다른 거르기(`categoryId`·`saleState`)와 함께 쓰고, 순서·쪽(`cursor`)은 지금과 같게.
- 가능하면 SKU 코드(`E-…`/`B-…`)·바코드를 `q` 로 넣어도 그 상품이 나오면 좋겠다. 지금은 화면이 `GET /skus/{sku}`·`GET /barcodes/{barcode}` 로 따로 찾는다 — 안 되면 그대로 둔다.

### PN-2 (선택) 고객용 상품명으로도

- 고객용 상품명(product-content `name`)으로도 찾고 싶다. product-service 와 product-content 가 다르면 어느 쪽이 맡을지 알려 달라. 어렵다면 PN-1 만으로 충분하다.

## 받으면 화면

- 상품명 칸에 넣은 말을 `q` 로 보내 서버가 찾게 하고, "이 쪽 안에서만" 안내를 지운다.
- 그 전까지는 지금처럼 이 쪽 안에서만 거른다(추측해 `q` 를 보내지 않는다).
