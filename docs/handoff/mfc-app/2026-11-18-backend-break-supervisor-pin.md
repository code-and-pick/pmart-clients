# [pmart-clients → pmart-backend] 요청: 휴게는 관리자 번호로만 켜고, 정한 휴게 시간에는 자동 휴게 (2026-11-18)

- 보낸 앱: mfc-app (PC 3) — mfc-backoffice(PC 3)도 같이 쓴다
- 받는 백엔드 영역: mfc (capacity — 휴게·근무)
- 사용자 결정(2026-11-18):
  - PDA에 휴게 단추는 둔다. 다만 작업자가 혼자 켤 수는 없고, **센터 관리자가 정한 4자리 번호**를 받아야 켜진다. 이 번호는 로그인 비밀번호와 따로다.
  - 휴게는 **서버가 정한 휴게 시간에 자동으로** 되게 한다.

## 지금(mfc-capacity 계약)
- `POST /mfcs/{mfcId}/workers/{workerId}/breaks`는 본인 또는 그 센터 관리자가 부르고, 본문이 없다. 그래서 작업자가 언제든 혼자 휴게를 켤 수 있다.
- 휴게 시간을 정하거나 자동으로 휴게가 되는 것은 없다. Q-09(휴게·교대 규칙)는 아직 정하지 않았다.

## 요청

### B1. 센터 휴게 번호(관리자가 정함)
- 센터마다 4자리 숫자 하나. 정하고 바꾸는 것은 그 센터 `MFC_SUPERVISOR`만 할 수 있다. mfc-backoffice 화면에서 쓴다.
- 서버에는 해시로만 둔다. 어떤 응답에도 번호를 돌려주지 않고, 로그·사건에도 남기지 않는다.
- 조회는 "정했는지·언제 바꿨는지"만 준다.
- 예시(이름은 백엔드가 정한다): `PUT /mfcs/{mfcId}/break-pin {pin}`, `GET /mfcs/{mfcId}/break-pin` → `{set, updatedAt, updatedBy}`.

### B2. 작업자 본인이 휴게를 켤 때는 번호 확인
- `startWorkerBreak` 본문에 `supervisorPin`(4자리)을 받는다. **작업자 본인 토큰이면 꼭 있어야 한다.** 센터 관리자·서비스 토큰은 번호 없이 된다(mfc-backoffice 휴게 단추와 B3 자동 휴게).
- 거절 코드(이름은 바꿔도 된다. 정해지면 PDA를 맞춘다):
  - `BREAK_PIN_INVALID`: 번호가 다르다.
  - `BREAK_PIN_LOCKED`: 연속으로 여러 번 틀렸다. 4자리는 1만 가지라 잠금이 꼭 있어야 한다. PDA는 지금 5번이라고 가정했다. 횟수, 풀리는 조건(시간 또는 관리자)은 정해서 회신에 적어 주세요.
  - `BREAK_PIN_NOT_SET`: 센터가 번호를 아직 정하지 않았다.
- 거절도 확정 결과다. 같은 `Idempotency-Key`로 다시 보내면 같은 판정을 돌려준다.
- **휴게 끝**(`…/breaks/current/end`)은 번호 없이 지금처럼 둔다. 사용자는 "켤 때만"이라고 했다.

### B3. 정한 휴게 시간에 자동 휴게
- 휴게 시간을 서버에 둔다. 근무(shift)마다든 센터 기본값이든 백엔드가 정한다. 그 시간이 되면 서버가 작업자를 휴게로, 끝나면 휴게 끝으로 바꾼다.
- 정할 것이 있으면 회신에 적어 주세요:
  - (a) 휴게 시간은 누가·어디서 정하나. mfc-backoffice 화면이 필요하면 API도 같이.
  - (b) 시작 때 진행 중인 작업이 있으면 어떻게 하나. 제안: 들고 있는 작업은 끝낼 수 있고, 다음 작업 받기부터 `409 ON_BREAK`(지금 규칙과 같다).
  - (c) 자동 휴게 중에 작업자가 일찍 끝낼 수 있나(지금 휴게 끝 API), 관리자만 되나.
- PDA는 휴게 상태를 `getWorker`의 `onBreak`로 보여 준다. 자동 휴게도 이 값으로 보이면 PDA 쪽은 따로 바꿀 것이 없다.

## 클라이언트에서 한 것(PR 참고)
- PDA "휴게" 단추를 누르면 관리자 번호 4자리 창이 뜬다. 숫자만, 가려서 보이고, 저장·로그는 하지 않는다. 휴게는 서버가 받아들일 때만 켜진다.
  - 틀리면 번호를 지우고 다시 받는다. 잠김·미설정이면 창이 더 받지 않는다.
  - "휴게 끝"은 번호 없이 된다.
- **실서버에서는 B2 전까지 휴게를 켜지 않는다.** 계약에 번호가 없어서, 지금 API로 보내면 번호 없이 휴게가 켜진다. 대신 "관리자 확인을 아직 서버가 받지 않아요 — 센터 관리자에게 휴게를 요청해 주세요"를 보여 준다.
  - 그동안 휴게는 mfc-backoffice 작업자 화면의 휴게 단추(관리자)로 켠다.
- B1이 나오면 mfc-backoffice에 번호 설정 화면을 만들고, B2가 나오면 PDA가 번호를 실어 보내도록 바꾼다.
