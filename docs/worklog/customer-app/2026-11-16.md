## LAN APK — HTTPS 게이트웨이로
- 요청: 사용자 "apk 빌드 버전도 최신인지" → 11-15 10:44 빌드라 고객센터·AI 상담(2482f24·df930dc)·리뷰 사진(414628d)이 빠져 있었음 → 다시 빌드(http 8080, 10:30). 이어 백엔드 세션 안내(사용자가 붙여 줌): API 주소는 HTTPS `https://192.168.0.40:8443/api/v1`.
- 문제: Dart HTTP(Dio·`Image.network` 의 `HttpClient`)는 안드로이드 `network_security_config`·폰에 설치한 CA 를 쓰지 않는다 → 사설 CA(ADR-0057) 게이트웨이에 접속 못 함.
- 한 일: `pmart_core` `trustPmartLanRootCa()`(`lib/src/lan_trust.dart`) — 공개 루트 CA(원본 `pmart-backend/deploy/lan/tls/pmart-lan-root-ca.crt`, SHA-256 88:2B:…:3D:37, 만료 2036-11-09)를 `SecurityContext.defaultContext` 에 더한다(시스템 CA 는 그대로). 고객앱 `main` 이 release 가 아닐 때만 부른다(ADR-0057 T6 "lan/debug 빌드만"). 영향: 다른 Flutter 앱은 부르지 않으면 그대로(mfc_app·rider_app 이 HTTPS 로 옮길 때 같은 한 줄).
- 확인(이 PC, Dart, 시스템 CA 없이 이 CA 하나만): `GET https://192.168.0.40:8443/api/v1/products/P-0001/reviews` 200(빈 목록·summary null — 계약대로), `/me/notifications`·`/customer-assistant/recent-orders` 401 Problem(경로 있음).
- 빌드: `flutter build apk --debug --dart-define=PMART_ENV=local --dart-define=PMART_API_BASE_URL=https://192.168.0.40:8443/api/v1 --dart-define-from-file=.secrets/customer.env` 성공 → `apps/customer_app/build/app/outputs/flutter-apk/app-debug.apk`(245MB, 10:42). APK 안에 8443 주소·CA 가 들어간 것 확인. 기기 설치·Google 로그인·실서버 확인은 사용자(연결된 기기 없음).
- 검증: pmart_core analyze·test 42, customer_app analyze·test 358 통과.
