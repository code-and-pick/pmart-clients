- 지급 결과: 정산내역의 지급 중·지급 완료·지급 실패(settlementState PAYING·PAID·PAYMENT_FAILED)는 이미 그려지고 있었음 — 바꿀 것 없음. 알림함은 서버 제목·본문을 그대로 보여 RIDER_PAYOUT_PAID·RIDER_PAYOUT_FAILED·RIDER_APPEAL_DECIDED 도 따로 할 일 없음.

  - 정산내역 줄에 "이의 신청" → 수행료 이의(targetRef = deliveryId). 보이는 줄: 배송 ID 가 있고 산정 불가·조정·결과 안내(note)가 있는 줄 — 맞는지는 직원이 판단.

  - 마이페이지 "내 신청": 결정 대기·유지·인정 + 결정 이유.
  - 안내 문구는 "인정되면 수행료 조정을 따로 처리해요"(조정이 자동이 아니므로 약속하지 않음).
