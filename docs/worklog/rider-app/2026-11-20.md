- 한 일:
  - `features/auth/data/phone_identity.dart`: `ApiPhoneIdentityRepository`(시작·확인·짝 조회 GET). 저장소는 env 로 고름(목/Api, 더는 null 없음). 409 details(`[{field, reason}]`) → `identityConflictOf`(IDENTITY_ALREADY_REGISTERED: provider·emailMasked·joinedAt — provider·email 은 없을 수 있어 nullable, RIDER_REJOIN_BLOCKED: until). 시작 400 PHONE_NOT_SUPPORTED·VALIDATION_FAILED → 010 아님, 429 TOO_MANY_VERIFICATIONS → 하루 초과, 422 CONFIG_REQUIRED → 준비 중, 409 → `PhoneIdentityStartEnded`. 확인 503 DEPENDENCY_UNAVAILABLE → 혼잡(같은 키로 다시, 짝 조회 안 함), 응답 못 받음 → GET 짝 조회로 끝난 결과만 확정·아직이면 혼잡, 404 → 시간 지남.
  - 목도 서버처럼 다른 계정·탈퇴 번호를 **시작 때** 409 로 끝내게 바꿈(계약: 시작·가입이 409 를 줌, 확인은 주지 않음).
  - `phone_identity_screen.dart`: 시작 409 → 기존 안내 화면, CONFIG_REQUIRED → 준비 중 안내 + "확인 없이 계속"(가입을 받을지는 서버가 정함). 서버가 수단을 모르면 수단 줄·버튼 대신 "로그인 화면으로". 가입 409 용 `IdentityEndedScreen`(`/signup/identity-ended`).
  - `signup.dart`·`signup_screens.dart`: 가입 본문에 `phoneVerificationId`(건너뛰었으면 안 보냄), 409 IDENTITY_ALREADY_REGISTERED·RIDER_REJOIN_BLOCKED → 같은 안내 후 전화번호 단계, 422 PHONE_NOT_VERIFIED → 전화번호 단계 + 안내. 그 밖 실패는 안내(전에는 가입 실패 예외를 잡지 않아 버튼이 진행 중으로 멈췄다). 확정 거절(Problem) 뒤에는 새 멱등키, 결과 불명은 같은 키. 번호를 바꾸면 확인 ID 를 지움.
  - `rider_auth.dart`·`session.dart`·`login_screen.dart`: `riderAuthAcceptsKakaoNaver = true`(버튼은 빌드에 KAKAO_NATIVE_APP_KEY·NAVER_CLIENT_ID 가 있을 때만), `ra.Provider.KAKAO/NAVER` 로 보냄. 422 CONFIG_REQUIRED·UNSUPPORTED_ACTION → `RiderLoginProviderNotReady` → "{제공자} 로그인은 아직 준비 중" 안내 + 이 실행 동안 버튼 숨김(`unavailableSocialProvidersProvider`, 구글은 숨기지 않음). 로그아웃은 로그인한 제공자 SDK 를 로그아웃. "그 계정으로 로그인"(switchAccount)은 이전 세션 로그아웃·토큰 지우기를 기다린 뒤 로그인(늦게 끝난 로그아웃이 새 토큰을 지우던 경합 제거).
  - ARB: phoneIdNotReady·phoneIdSkip·existingToLogin·loginProviderNotReady·signupPhoneNotVerified·signupRejected·signupUnknown 추가, loginMisconfigured 에서 "Google" 뺌.
- 결정: 로그인 계약에는 IDENTITY_ALREADY_REGISTERED 가 없다(409 는 공통 Conflict) — 로그인에서는 따로 처리하지 않고 번호 확인·가입에서 안내(백엔드 회신 R5: 다른 수단 로그인 = 새 주체 → 번호 확인에서 R3).
