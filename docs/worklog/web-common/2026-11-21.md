# 2026-11-21 web-common (PC 2)

## 17:00 어두운 테마를 MFC 관제실 겉모습으로 — 공용 tower.css
- 계기: PC 3 알림 `docs/operations/2026-11-21-notice-web-ui-tower-design.md` §6 A안, 사용자 "어두운 테마 pc3 요청에 맞게 해봐 … 바꼈을 때 기능적으로 오류나거나 부자연스러운 ui 너가 뒤져서 찾아내고 고쳐". 밝은 테마는 AWS 그대로(사용자와 정함).
- `web/ui/src/tower.css`(새): `web/mfc-backoffice/src/index.css` 17~308행(색·바·패널·표·배지·단추·pm-action·pm-seg·pm-meter·pm-mono·pm-live·pm-pulse)을 옮김. 도면(pm-zone·pm-floor)·추이 차오르기(pm-chart)는 MFC 전용이라 남김. `web/backoffice`·`web/hr-backoffice` index.css 가 console.css 뒤에 읽음. MFC 쪽 중복 블록 정리는 PC 3 에 알림.
- 목 화면(두 앱 어두운 테마 20여 화면)에서 찾아 tower.css 에서 고친 것:
  1. 패널 `overflow: clip` → 패널 안 속성 필터 드롭다운이 패널 끝에서 잘려 고를 수 없었다(기능 오류) — 뺌.
  2. 패널 `backdrop-filter` → 패널마다 쌓임 층이 생겨 뒤 패널이 앞 패널 드롭다운을 덮었다 — 뺌(바탕 0.78 불투명이라 차이 거의 없음).
  3. 로고 그라데이션 선택자 `#root header > a > span` 이 본문 상세 머리(`<header>`)의 "‹ 목록" 화살표도 보라 덩어리로 칠함 — 바깥 머리줄로 좁힘.
  4. 주 단추 보라 그라데이션이 테두리형(btn-outline: 홈 편성 "+ 배너"·"+ 테마")에도 칠해져 글자가 안 보이고, 꺼진 주 단추(질문 보내기·다시 회수 요청)가 켜진 것처럼 보임 — 채운·켜진 주 단추만.
  5. 하위 메뉴 앞 점이 첫 span(통합은 알림 숫자) 앞에 붙어 숫자 앞에만 찍히고, 인사 웹은 양 끝 정렬이라 이름이 오른쪽으로 밀림 — `a::before` 위치 고정.
  6. 제목 자간(-0.045em)이 제목 안 꼬리표에도 먹어 "작성 중"이 "작성중"으로 — 꼬리표는 보통 자간.
- 확인: 밝은 테마 그대로, 메뉴 접힘, 로그인 화면(어두운), 확인 상자·단축키 안내. 두 앱 빌드 통과. 개발 서버 끔.
