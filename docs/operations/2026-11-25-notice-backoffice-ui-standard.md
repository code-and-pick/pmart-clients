## 0. 한 줄 요약
라이더 백오피스가 공용 콘솔 틀(`@pmart/web-ui` console.css·ConsoleShell) 위에 앱 안에서 덮어 쓴 **색·상자·표·목록 부품**을 공용으로 올린다. 그 뒤 통합·인사·MFC 백오피스가 같은 것을 쓴다. 각 앱의 **정보와 기능은 하나도 빼지 않는다.**

## 3. 모양 규칙
1. **색은 문제·주의·진행 중에만 쓴다.**
   - 상태는 7px 점 + 글자(`.pm-status`)로 보인다. 평상시 값은 보조 글색이다.
   - 줄·칸을 색으로 칠하지 않는다.
2. **문제 줄·알림은 판 색 + 왼쪽 3px 띠다.**
   - 빨강·주황으로 꽉 채운 상자를 쓰지 않는다(daisyUI alert 도 같다).
3. **상자:** 둥글기 10px, 1px 선, 그림자 없음.
4. **표:**
   - 머리는 보조 글색 600 + 아래 1px 선이다.
   - 줄 사이는 1px 선, 마우스를 올리면 `--pm-soft`, 줄무늬는 없다.
   - 숫자는 고정폭(`tabular-nums`)이다.
   - 값이 0이면 보조 글색이다.
5. **번호 링크(사람·배송·주문·작업 번호 → 상세)는 점선 밑줄이다.** 누르면 상세로 간다는 표시다. 단추 모양 링크는 제외한다.
6. **고른 칩:** 옅은 판 + 파랑 글자 + 1px 파랑 테두리(꽉 채우지 않는다).
7. **정렬(최신순|과거순):** 떨어진 작은 알약으로 둔다. 고른 것만 옅은 파랑이다.
8. **할 일 0건:** 초록 성공 상자가 아니라 판 위 회색 한 줄(`.pm-empty-line`)이다.
9. **불러오기 실패·권한 없음·결과 확인 중:** 위에서 아래로 보인다(제목 → 한 줄 설명 → 문의 번호 → 다시 시도). 글자가 세로로 꺾이지 않는다.

## 4. 글
- **회색 설명 글은 짧게, 아니면 없앤다.** 제목 옆 `ⓘ`(화면 설명) 단추와 "ⓘ 화면 안내" 줄도 **그리지 않는다**(2026-11-24 사용자 "i 원문자 제목 옆에 안내 버튼 없애"·"화면 안내 … 다른 탭에서도 다 없애"). 처음 판에 "ⓘ 로 접는다"고 잘못 적었다(2026-11-25 고침, §12).
- 탭·화면 맨 위의 안내 상자는 두지 않는다.
- 단추·칸 이름은 하는 일을 그대로 쓴다(예: "지급 실패 다시 보내기"). 내부 용어·코드·영문 상태값은 화면에 쓰지 않는다.
- 한 줄로 읽히게 쓴다. 두 줄로 꺾이는 긴 설명은 접거나 줄인다.
- 글을 줄여도 **정보는 줄이지 않는다.** 숨기는 것은 설명뿐이고, 값·기능은 그대로 보인다.

## 5. 목록 화면 한 틀(모든 메뉴 공통)
위에서 아래로 이 순서로 둔다.
1. **머리:** 제목(ⓘ 없음) · 오른쪽에 그 화면의 주 동작 1개, 나머지는 보통 단추.
2. **숫자 띠(StatCard):** 그 목록의 건수·금액 칸. 칸을 누르면 그 조건으로 걸린 아래 목록이 된다.
3. **찾기 줄**(숫자 띠와 28px 띄움, 목록 쪽에 붙음):
   - 한 줄에 `[찾기 칸][찾기][깔때기 → 팝업(상태·종류 고르기, ✓ + 이름 + 건수)][건 조건 칩 ✕][초기화]` 를 둔다.
   - 거르기는 모두 팝업 안에 있고, 건 조건은 칩으로 늘 보인다.
4. **결과 줄:** 건수 · 정렬 알약.
5. **표:**
   - 줄을 누르면 **줄 아래 펼침**(옅은 판 + 아래 파랑 2px)으로 요약을 보인다. 펼침 안에 "전체 상세 ›" 를 둔다.
   - 번호 링크는 바로 상세로 간다.
6. **상세:**
   - "보기" 구역(조용한 판)과 "처리" 구역(왼쪽 파랑 띠 + "처리" 머리)으로 나눈다.
   - 1600px 이상에서만 좌우 두 칸이고, 그보다 좁으면 위아래다.
   - 처리 카드는 걸린 값을 크게 보이고, 입력은 순서대로(1→2→3) 받고, 결과를 미리 보인다.

## 5-1. 상세 화면 머리(빠뜨려서 2026-11-25 덧붙임 — 사용자 지적 "제목 앞 원 안 < 되돌리기")
정본: `web/rider-backoffice/src/shared/admin.tsx` 의 `DetailHeader`·`BackButton`·`useGoBack`, `shared/StickyTitle.tsx`.
- **제목이 맨 위다.** 제목 위에 "‹ 홈 진열 편성" 같은 글자 링크(빵부스러기식 뒤로)를 두지 않는다.
- **제목 바로 왼쪽에 둥근 ‹ 단추** — 흰 판 + 1px 선 원(`btn btn-circle btn-sm`, ‹ 글자 xl). 이름(어디로 가는지)은 마우스 올림·읽기 도구에만(`title`·`aria-label`, 예 "라이더 찾기로").
- 누르면 **방금 보던 화면으로**(브라우저 기록이 있으면 뒤로, 없으면 목록으로) — 돌아오면 찾기 조건·스크롤이 그대로.
- 순서: [‹][제목][상태 점·꼬리표] — 오른쪽 위에 이전·n/N·다음(마지막으로 본 목록 순서, `[` `]` 키)과 그 화면 동작 단추.
- 제목 밑 요약 글은 한 줄, 작고 옅게(제목과 8px 띄움).
- 내려서 제목이 화면 위로 지나가면 위에 얇은 제목 띠(같은 ‹ 작은 단추 + 제목)가 붙는다.
- 상세 안 항목/값(`FieldList`): 항목명 작은 회색, 값은 조금 크고 굵은 짙은 글자, 값이 두 줄로 꺾이지 않게 칸 폭 최소 11rem.

## 6. 연결
- **대시보드 → 목록:** 숫자 칸·할 일 줄을 누르면 그 조건이 걸린 목록으로 간다.
- **목록 → 상세 → 뒤로:** 돌아오면 찾기 조건·스크롤·펼친 줄을 그대로 둔다.
- **상세 안 다른 대상:** 사람·배송·주문 번호는 점선 링크로 그 상세로 간다.
- **메뉴 배지:** 처리할 것이 있는 메뉴에는 건수 배지를 단다.
- 어디서 왔는지 머리에 짧게 둔다. 빵부스러기가 있는 앱은 그대로 쓴다.

## 7. 바꾸지 않는 것(각 세션이 일부러 만든 것)
아래는 **모양 통일 대상이 아니다.** 색 변수만 따라오고, 구조·그래프 모양·기능은 그 앱 담당 세션이 정한다. 바꿔야 할 것 같으면 그 세션에 먼저 묻는다.
- **MFC 백오피스(PC 3):**
  - 관제실 화면 구조(층 지도·작업 흐름·실시간 움직임).
  - 대시보드 그래프 모양.
  - 움직임 규칙(`2026-11-21-notice-web-ui-tower-design.md`).
- **통합 백오피스(PC 2):**
  - AWS 콘솔식 뼈대(빵부스러기·도움말 패널·분할 상세·표 설정·저장한 보기, `docs/apps/backoffice-ui-guide.md`·ADR-0004).
  - 재고 실시간 칸.
  - 칸반.
- **인사 백오피스(PC 2):** 직원 등록·계정 발급 흐름.
- **라이더 백오피스(PC 5):**
  - 관제 지도.
  - 대시보드 시간대 칸(히트맵).
  - 분석 구역 그래프.

## 8. 하는 순서
1. **공용으로 올리기 — PC 2(web-common):**
   - `sim-look.css`·`sim-list.css` 의 공통 규칙을 `web/ui/src/` 새 파일(예: `standard.css`)로 옮긴다. 각 앱 `index.css` 가 `console.css` 뒤에 읽는다.
   - MFC 관제실 덮어쓰기는 MFC `index.css` 에 남아 그 뒤에 읽히므로 MFC 의 **구조·움직임 규칙**은 그대로다. 다만 **색**은 §2로 맞춘다(아래 앱별 요청).
   - `simList.tsx` 의 목록 부품과 `admin.tsx` 의 StatCard·StatusText·AllDone 을 `web/ui` 로 올린다. 라이더 백오피스는 올린 뒤 공용 것을 쓰게 PC 5가 바꾼다.
2. **앱마다 적용 — 각 담당:** `index.css` 에서 공용 표준을 읽고, §5 목록 틀을 메뉴마다 맞춘다. 메뉴마다 정보·기능이 빠지지 않았는지 §9로 확인한다.
3. **확인:** 메뉴마다 밝음·어두움 두 장씩 캡처해 라이더 백오피스와 나란히 본다(목 모드).

## 10. 앱별 요청
### 통합 백오피스·인사 백오피스(PC 2)
1. **어두운 테마:**
   - 지금 공용 `tower.css`(MFC 관제실 남색·보라)를 읽는다. §2의 어두움 값(검정 회색 + 파랑)으로 바꾼다.
   - `index.css` 의 `tower.css` 읽기를 표준으로 바꾸면 된다.
2. **밝은 테마:**
   - console.css 값에서 바꾼다: 둥글기 2px/4px → 10px/6px, 바탕 `#f9f9f9` → `#f4f5f7`, 강조 `#295eff` → `#2563eb`.
   - 상태 꼬리표(알약)를 점 + 글자로 바꾼다.
3. **목록 메뉴:**
   - §5 틀로 맞춘다.
   - 통합 백오피스의 AWS 뼈대(빵부스러기·도움말 패널·표 설정·저장한 보기)는 남기고, 그 안의 찾기 줄·표·상태 모양만 맞춘다.
4. **회색 설명 문장:** 이미 도움말 패널로 옮긴 것은 그대로 둔다. 화면에 남은 긴 회색 글은 줄이거나 뺀다(ⓘ 단추 없음).
5. **web-common:** §8-1(공용으로 올리기)을 먼저 해 주면 다른 앱이 따라 붙기 쉽다.
