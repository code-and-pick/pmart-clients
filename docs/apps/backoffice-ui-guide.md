# 백오피스 UI·UX 개편 기준 — AWS 콘솔 모양 (시범)

- 상태: **시범 — `web/backoffice` 에만 적용한다.** 인사팀·MFC·라이더 백오피스는 지금 형식(라이더 백오피스 관리자 형식) 그대로. 결정·넓힐 조건은 [ADR-0004](../adr/0004-backoffice-aws-console-style-pilot.md).
- 작성: 2026-11-20, PC 2(백오피스). 사용자 지시 "백오피스 UI UX 를 전면 개정한다. 레퍼런스는 AWS 콘솔".
- 방법: 로그인된 AWS 콘솔(2026-11 한국어 화면)을 읽기만 하며 둘러보고 캡처했다.
  - 둘러본 화면: 콘솔 홈, EC2 대시보드·인스턴스·인스턴스 유형·인스턴스 시작·유형 파인더, IAM 대시보드·역할·역할 상세, CloudWatch 개요·경보, 결제 대시보드.
  - 표·필터 메뉴·표 설정 창·도움말 패널은 열어서 보고 닫았다(저장·생성 없음).
  - 수치는 IAM 역할 화면에서 브라우저 계산값(getComputedStyle)을 읽었다.
- **캡처는 `web/aws-ui-reference/`(git 제외)에 있다** — 계정 번호·사용자 이름이 찍혀 있어 저장소에 넣지 않는다. 그 폴더가 있는 PC(PC 2)에서만 볼 수 있다. 장마다 "캡처:" 에 파일 이름 앞부분(예: `09-IAM-역할목록`)을 적는다.
- AWS 콘솔은 공개 디자인 시스템 **Cloudscape**(cloudscape.design, Apache-2.0)로 만들어진다. 아래 이름(App layout·Table·Property filter·Split panel·Help panel 등)은 Cloudscape 부품 이름이다.
- 우리는 daisyUI 5 + Tailwind 4 를 그대로 쓰고(새 UI 라이브러리를 들이지 않는다 — react-web 규칙), **모양과 규칙만** 따른다.

## 0. 시범 범위와 고치는 곳
- 고치는 곳은 backoffice 안에서만:
  - 디자인 토큰 — `web/backoffice/src/index.css` 의 daisyUI 테마 변수.
  - 화면 부품 — `web/backoffice/src/shared/admin.tsx`(앱마다 사본, ADR-0004 결정 2).
  - 화면 — `web/backoffice/src/features/**`.
- **고치지 않는 곳**: `web/ui`(`@pmart/web-ui`)·`web/core`, 공용 `motion.css`·`wing.css`, 다른 웹 앱. 공용 부품이 새 모양과 안 맞으면 backoffice 안에서 감싸는 부품을 두거나 backoffice CSS 로 덮는다.
- 로그인 화면과 로그인 시험은 PC 1 몫 — 머리줄을 바꿀 때 로그인 시험이 찾는 글자("내 세션" 등)는 그대로 둔다.
- 업무 규칙(서버 확정만 확정 표시·조회 실패를 빈 목록으로 보이지 않기·개인정보 마스킹·화면 용어)은 모양을 바꿔도 그대로다.

## 1. 첫인상 — 무엇이 다른가
- **조용하다.** 바탕은 거의 흰색, 색은 상태(초록·빨강·주황)와 링크·선택(파랑)에만 쓴다. 카드 그림자·두꺼운 테두리·그라데이션이 없다.
- **촘촘하다.** 본문 14px, 표 줄 높이 38px, 버튼 높이 30px. 한 화면에 정보가 많이 들어간다.
- **모든 화면이 같은 뼈대다.** 머리줄 → 빵부스러기 → 왼쪽 메뉴 → 본문(제목 + 동작 버튼 → 내용) → (필요할 때) 오른쪽 도움말·아래 분할 상세. 서비스가 달라도 위치가 같아 배우지 않아도 쓴다.
- **동작은 오른쪽 위에 모은다.** 화면의 주요 동작 1개만 검은 "주 버튼", 나머지는 흰 테두리 버튼, 여러 동작은 "작업 ▾" 메뉴 하나로.

## 2. 뼈대(App layout)
| 자리 | AWS | 우리에게 |
|---|---|---|
| 맨 위 머리줄(높이 약 44px) | 로고 · 서비스 검색(가운데, `[알트+S]` 단축키 표시) · 오른쪽 아이콘(셸·알림·도움·설정) · 지역 · 계정 | 로고 · 번호 검색(Ctrl K, 이미 있음) · 알림 · 도움 · 내 세션. 다크 머리줄이 아니라 **흰 머리줄 + 아래 1px 선** |
| 두 번째 줄 | 메뉴 열고 닫기 아이콘 · 빵부스러기 `EC2 / 인스턴스 / 인스턴스 시작` (밑줄 링크, `/` 구분) · 오른쪽 끝 도움말(ⓘ) 아이콘 | 지금 머리줄의 빵부스러기를 이 줄로. 오른쪽 끝에 도움말 열기 |
| 왼쪽 메뉴(폭 약 220px) | 맨 위 서비스 이름(굵게 18px) + 접기 `<` · 묶음 제목(굵게, `∨` 접힘) · 항목(14px, 높이 30px) · 지금 항목은 **파랑 글자 + 굵게**(바탕색 없음) · "신규" 파랑 꼬리표 · 메뉴 안 검색칸(IAM) | 지금 어두운 남색 사이드바 → **흰 바탕 메뉴**로. 지금 항목 표시는 파란 바탕 칩 → 파랑 굵은 글자로 |
| 본문 | 왼쪽 정렬, 바탕 #f9f9f9 위에 흰 컨테이너 | 같은 바탕 |
| 오른쪽 도움말(Help panel, 폭 약 240px) | 제목 옆 "정보" 링크를 누르면 오른쪽에 열린다 — 뜻 설명·"콘텐츠가 도움이 되었나요?"·자세히 알아보기 | 지금 지운 회색 안내 문장들을 여기로(화면에는 안 보이고, 궁금할 때만) |
| 아래 분할 상세(Split panel) | 표에서 줄을 고르면 **아래쪽**에 상세가 열린다(가운데 끌기 막대 `—`로 높이 조절, 오른쪽 `∨`로 접기). 탭(세부 정보·컴퓨팅·네트워킹…) | 상품 조회·가격 관리의 오른쪽 서랍을 아래 분할 상세로 바꿀 수 있다 |
| 맨 아래 바닥줄(높이 약 28px) | CloudShell · 의견 · 저작권 · 개인정보 · 약관 · 쿠키 | 필요 없으면 뺀다 |

## 3. 목록 화면(Table) — 가장 많이 쓰는 모양
캡처: EC2 인스턴스 유형, IAM 역할, CloudWatch 경보.

1. **제목줄**:
   - 왼쪽: `역할 (3)` — 제목 24px 굵게, 개수는 같은 크기 회색 괄호 · 바로 옆 파랑 작은 "정보" 링크 · 아래 회색 설명 한 줄(선택).
   - 오른쪽: `[↻ 새로 고침 아이콘] [삭제] [작업 ▾] [역할 생성(검정)]`. 줄을 고르기 전에는 "삭제"처럼 고른 줄에만 쓰는 버튼이 **꺼진 채 보인다**.
   - 마지막으로 읽은 시각: `Last updated / less than a minute ago`를 새로 고침 옆에 작게 둔다.
2. **필터줄**:
   - 왼쪽 큰 검색칸(폭 약 540px, 돋보기 아이콘, 자리표시자 "속성 또는 태그를 기준으로 … 필터링").
   - 오른쪽 끝: 쪽 넘김 `< 1 2 3 … 17 >`와 톱니(표 설정).
   - 필요하면 검색칸 왼쪽에 "저장한 필터 세트 ▾", 오른쪽에 "퀵 필터 ▾" 고르기 상자.
3. **검색칸 = 속성 필터(Property filter)**:
   - 누르면 아래로 "속성 목록"이 뜬다. 속성을 고르거나 치면 연산자(`=`·`>=`·`<=`·`<`·`>` + "같음·크거나 같음…" 설명)가 이어 나온다.
   - 고르면 검색칸 아래에 `vCPU >= 8 ✕` 같은 **칩**으로 남고, 칩 사이 "and/or"를 고른다.
   - **탭·칩·고르기 상자를 따로 늘어놓지 않고 검색칸 하나에서 다 거른다.**
4. **표**:
   - 머리줄: 바탕 #f9f9f9, 글자 14px 500 회갈색(#4c4942), 아래 1px #e3e1de, 정렬 표시 `▲/▽`, 열 경계에 세로 구분선(크기 조절 손잡이).
   - 줄: 높이 38px, 줄 사이 1px #eeedeb. **줄무늬 없음**. 마우스를 올리면 아주 연한 바탕. 고른 줄은 연한 파랑 바탕 + 파랑 테두리.
   - 첫 칸 체크박스(여러 개 고를 때) 또는 라디오(하나만).
   - 이름 칸은 **점선 밑줄 링크**(검정 글자) — 누르면 상세 화면으로. 줄의 나머지를 누르면 줄 선택(→ 아래 분할 상세).
   - 값이 없으면 `-`. 상태는 **아이콘 + 색 글자**(`✓ 정상`·`⚠ 경보`·`⊖ 데이터 부족`) — 알약 꼬리표가 아니다.
   - 가로로 길면 표 안에서 가로 스크롤(표 아래 스크롤 막대). 화면 전체가 밀리지 않는다.
5. **빈 화면**:
   - 표 머리줄은 그대로 두고 가운데에 굵은 "인스턴스 없음" → 회색 "이 리전에는 인스턴스가 없음" → 흰 버튼 "인스턴스 시작".
   - 아이콘·그림 없이 세 줄.
6. **표 설정(톱니) 창**:
   - 왼쪽 "페이지 크기(20·50·100 라디오)·줄 바꿈(체크)", 오른쪽 "표시되는 열 선택(토글 목록)".
   - 아래 "취소 / 확인(검정)". 사용자가 열을 끄고 켠다.

## 4. 상세 화면
캡처: IAM 역할 상세, EC2 분할 상세.

- 제목줄: 이름(24px 굵게) + 파랑 "정보" · 아래 회색 설명 한 줄 · 오른쪽 위 "삭제"(흰 버튼, 위험 동작도 빨간색이 아니다 — 누르면 확인 창).
- **요약 컨테이너**: 흰 상자 안에 제목 "요약"(20px 굵게) + 오른쪽 "편집" 버튼. 내용은 **2~4열 이름/값 칸**(Key-value pairs).
  - 이름은 회색 작은 글자.
  - 값은 검정 14px.
  - 복사할 값 앞에 복사 아이콘(⧉).
  - 상태 값은 `✓ 2개월 전`처럼 아이콘 + 초록 글자.
- **탭**: 요약 아래 밑줄 탭(권한·신뢰 관계·태그·마지막 액세스). 지금 탭은 파랑 굵은 글자 + 파랑 밑줄 2px. 탭 사이 세로 구분선.
- 탭 안 내용도 같은 규칙의 컨테이너(`권한 정책 (1)` 제목 + 새로 고침 + 검색 + 필터 고르기 + 표).

## 5. 만들기·입력 화면(Form, 마법사)
캡처: EC2 인스턴스 시작, 인스턴스 유형 파인더.

- 본문 폭을 줄여 가운데(약 1320px)로. 맨 위 제목 + 회색 설명.
- 입력은 **주제별 컨테이너(섹션)** 로 나눈다(이름 및 태그 · 이미지 · 인스턴스 유형 · 키 페어 · 네트워크 설정…). 각 섹션 제목 왼쪽 `∨`로 접기, 제목 옆 "정보".
- 칸: 위에 굵은 이름(14px) → 아래 회색 설명(선택) → 입력칸(높이 32px, 테두리 1px 회색, 둥글기 4px) → 칸 아래 회색 도움말/빨강 오류. 필수는 이름 뒤 "- *필수*"(기울임).
- **오른쪽 고정 "요약" 상자(sticky)**: 고른 값들을 이름/값으로 모아 보이고, 맨 아래 "취소"(글자 버튼) + 주 버튼("인스턴스 시작", 검정). 스크롤해도 따라온다.
- 짧은 폼(유형 파인더)은 컨테이너 하나 + 2열 칸 + "고급 파라미터 >" 접기 + 오른쪽 아래 "취소 / 주 버튼".
- 안내·경고는 섹션 안의 **띠(Alert)**:
  - 정보: 연파랑 바탕 + ⓘ
  - 경고: 연노랑 바탕 + ⚠ — "이 리전에는 VPC 가 없는 것으로 확인했습니다… 새 VPC를 생성하세요"
  - 오른쪽에 `✕` 닫기
  - 문장 안에 바로 갈 링크를 둔다.

## 6. 대시보드
캡처: 콘솔 홈, EC2 대시보드, IAM 대시보드, 결제 대시보드, CloudWatch 개요.

- **위젯 = 흰 컨테이너**. 제목(20px 굵게) + "정보" + 오른쪽 위 `⋮`(위젯 메뉴)·`⚙`·`✕`. 왼쪽 위 `⠿`(끌어서 자리 옮김), 오른쪽 아래 크기 조절 손잡이. 오른쪽 위 "+ 위젯 추가"·"기본 레이아웃으로 재설정".
- **숫자 칸**: 회색 이름 → 큰 숫자(20~24px). 칸 사이 세로 구분선. 숫자는 누르면 그 목록으로 가는 **밑줄 링크**(IAM 리소스: `역할 3`). 숫자 옆 비교 `↓ 0.0%`.
- **리소스 격자**(EC2 대시보드): `인스턴스(실행 중) 0` 같은 이름/숫자 칸을 3열 격자로 — 각 칸은 1px 테두리, 이름은 점선 밑줄 링크.
- 위젯 바닥에 가운데 정렬 링크 한 줄("AWS Health로 이동", "청구서 보기", "Cost Explorer에서 비용 분석 ↗").
- 시간 범위는 오른쪽 위 **분절 버튼**(`1시간 3시간 12시간 1일 1주 사용자 지정`) + 시간대 고르기 + 새로 고침 ▾ + 전체 화면.
- 차트는 막대·선 두 가지, 색은 적게(리전 2개 = 파랑·자주), 범례는 아래.

## 7. 낱말·문장 규칙(UX writing)
- 버튼은 **동사 + 대상**: "역할 생성", "인스턴스 시작", "경보 생성", "필터 세트 선택". 확인 창은 "취소 / 확인".
- 숫자는 제목 옆 괄호 `역할 (3)`, 고르면 `(1/811)`.
- 빈 화면은 "무엇이 없다(굵게) → 왜·어디(회색) → 만들기 버튼" 세 줄.
- 설명이 긴 것은 화면에 쓰지 않고 "정보" → 도움말 패널로.
- 바깥으로 나가는 링크는 끝에 `↗` 아이콘.
- 시각은 "10분 전·91일 전"(상대) + 마우스를 올리면 정확한 시각. 기준 시각이 중요한 화면은 "페이지 새로 고침 시간: 2026년 11월 20일 …"을 제목 아래에.

## 9. 지금 백오피스와 다른 점(개편 때 바꿀 것)
| 지금 백오피스 | AWS 방식 |
|---|---|
| 어두운 남색 왼쪽 메뉴, 지금 항목은 파란 바탕 칩 | 흰 메뉴, 지금 항목은 파랑 굵은 글자 |
| 카드마다 그림자·둥근 모서리(daisyUI rounded-box) | 1px 테두리 + 2px 둥글기, 그림자 없음 |
| 주 버튼 파랑(btn-primary) | 주 버튼 검정 1개, 나머지 흰 테두리 버튼, 여러 동작은 "작업 ▾" |
| 상태는 색 알약 꼬리표(badge) | 아이콘 + 색 글자 |
| 목록 위 숫자 카드·탭·칩·고르기 상자가 따로 | 검색칸 하나(속성 필터 + 칩) + 필요하면 퀵 필터 하나 |
| 오른쪽 미리보기 서랍 | 아래 분할 상세(줄 고르기) + 이름 링크는 상세 화면 |
| 설명 문장을 지웠다 | 지운 설명은 "정보" → 오른쪽 도움말 패널로 되살린다 |
| 표 열이 고정 | 톱니 → 표 설정(쪽 크기·열 켜고 끄기·줄 바꿈) |
| 대시보드 카드 고정 | 위젯(⋮ 메뉴, 숫자는 목록 링크). 끌어 옮기기는 나중 |
| 머리줄에 빵부스러기 | 두 번째 줄에 빵부스러기 + 오른쪽 도움말 아이콘 |
